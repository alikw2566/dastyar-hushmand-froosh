# داشبورد مکالمه‌بان

رابط فارسی و راست‌چین سامانه هوش مکالمه فروش. این برنامه بدون داده نمونه شروع
می‌شود و کاربر ناشناس را به ورود یا ساخت حساب هدایت می‌کند.

## پیش‌نیاز

- Node.js `>=22.13.0`

## اجرای محلی

```powershell
npm.cmd install
npm.cmd run dev
```

آدرس برنامه: `http://localhost:3000`

در اجرای محلی، اطلاعات حساب، تماس‌ها، وظایف و تنظیمات در D1 محلی و فایل صوتی در
R2 محلی نگهداری می‌شود. برای اتصال به بک‌اند کامل متغیر `API_BASE_URL` و تنظیمات
OIDC را تعریف کنید؛ در آن حالت پردازش صوت و تحلیل هوش مصنوعی توسط FastAPI و
Worker انجام می‌شود.

## فرمان‌های بررسی
