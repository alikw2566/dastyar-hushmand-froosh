# مکالمه‌بان — هوش مکالمه برای تیم فروش

«مکالمه‌بان» سامانه چندشرکتی فارسی برای رونویسی و تحلیل تماس‌های فروش است که برای شرکت فرازما توسعه داده شده است. محصول
شامل داشبورد مدیریتی، متن کامل تماس، تحلیل ساختاریافته، امتیاز فروشنده، KPI،
پیگیری، پیام پیشنهادی، مربیگری تیم، جست‌وجوی مکالمات و پنل مدیریت است.

## اجزای پروژه

- `web/`: داشبورد فارسی و RTL، API آپلود سبک برای Sites و ذخیره‌سازی D1/R2
- `backend/`: API اصلی FastAPI، PostgreSQL، پردازش GPT‑4o و Workerهای Celery
- `docker-compose.yml`: اجرای خصوصی با PostgreSQL، Redis، MinIO و Keycloak
- `test.py`: ابزار خط فرمان قدیمی برای پردازش یک فایل بدون داشبورد

## اجرای سریع روی ویندوز (بدون Docker)

```powershell
cd "C:\Users\LOQ\OneDrive\Documents\voice agent farazma\web"
npm.cmd install
npm.cmd run dev
```

سپس `http://localhost:3000` را باز کنید. کاربر ناشناس مستقیماً به صفحه ورود و
ساخت حساب هدایت می‌شود. بعد از ثبت‌نام، یک فضای کاری خالی و مستقل ساخته می‌شود؛
هیچ مشتری، تماس، فروشنده یا عدد نمونه‌ای نمایش داده نمی‌شود.

در این حالت سبک، این قسمت‌ها بدون Docker کار می‌کنند:

- ثبت‌نام، ورود و خروج امن محلی
- جداسازی اطلاعات حساب‌ها و شرکت‌ها
- داشبورد و آمار مبتنی بر داده واقعی
- آپلود و نگهداری فایل تماس
- فهرست و جزئیات تماس‌ها
- ساخت و تکمیل وظیفه پیگیری
- تأیید پیش‌نویس پیام
- ویرایش تنظیمات شرکت

رونویسی و تحلیل GPT در حالت سبک اجرا نمی‌شود. برای تولید متن کامل، تحلیل فروش،
KPI و پیام پیشنهادی باید اجرای کامل خصوصی را راه‌اندازی کنید.

## اجرای کامل خصوصی

پیش‌نیازها: Docker Desktop روشن، Node.js و یک کلید معتبر OpenAI. ابتدا فایل
تنظیمات Docker را بسازید و `OPENAI_API_KEY` را فقط داخل فایل `.env` ریشه قرار
دهید:

```powershell
Copy-Item .env.example .env
docker compose up --build
```

فایل `backend/.env` فقط زمانی لازم است که FastAPI را بیرون از Docker و مستقیم
اجرا کنید.

سپس این سرویس‌ها در دسترس‌اند:

- داشبورد: `http://localhost:3000`
- مستندات API: `http://localhost:8000/api/v1/docs`
- پنل Keycloak: `http://localhost:8081`
- پنل MinIO: `http://localhost:9001`

در محیط عملیاتی `AUTH_DISABLED=false` باشد و Keycloak باید claimهای `tenant_id`
و `role` را داخل Access Token قرار دهد. تمام جدول‌های مربوط به داده مشتری از
سیاست Row-Level Security استفاده می‌کنند.

در نصب خصوصی فعلی، کاربر تازه‌ثبت‌نام‌شده برای امکان آزمایش همه صفحات نقش مدیر
می‌گیرد. قبل از انتشار عمومی باید این رفتار با دعوت کاربر و تعیین نقش توسط مدیر
جایگزین شود.

## جریان پردازش تماس

1. فایل صوتی با ثبت رضایت ضبط، از آپلود، API یا اتصال تلفنی دریافت می‌شود.
2. فایل در Object Storage و اطلاعات آن در دیتابیس ذخیره می‌شود.
3. Worker با `gpt-4o-transcribe-diarize` متن گوینده‌بندی‌شده را تولید می‌کند.
4. GPT‑4o تحلیل فروش را طبق JSON Schema نسخه‌دار می‌سازد.
5. شواهد، KPI، امتیاز، اقدام بعدی و پیش‌نویس پیام در داشبورد نمایش داده می‌شوند.

خروجی مدل مستقیماً به‌عنوان HTML اجرا نمی‌شود؛ گزارش‌ها از داده ساختاریافته
رندر می‌شوند تا امن، قابل جست‌وجو و قابل مقایسه باشند.

## پنل مدیریت

مدیر شرکت از آیکون کوچک مدیریت در صفحه ورود یا دکمه «پنل مدیریت» داخل منوی
داشبورد وارد مرکز کنترل می‌شود. پنل شامل نمای مدیریتی، کاربران و نقش‌ها، تیم‌ها،
KPI و چک‌لیست امتیاز، اتوماسیون‌ها، اتصال‌ها، تنظیم مدل‌های AI، امنیت و نگهداری
داده و گزارش فعالیت است. تمام تغییرات در دیتابیس ذخیره و به `tenant_id` همان
شرکت محدود می‌شوند؛ فروشنده و سرپرست به APIهای مدیریتی دسترسی ندارند.

در اجرای محلی، افزودن عضو همراه رمز موقت یک حساب واقعی می‌سازد. در اجرای کامل،
همان عملیات کاربر را از طریق Keycloak ایجاد می‌کند و در اولین ورود تغییر رمز را
اجباری می‌سازد.

## وضعیت نسخه

این مخزن در وضعیت پیش‌انتشار است. ورود، چندشرکتی، آپلود، تماس‌ها، وظایف، پیام‌ها
و پنل مدیریت واقعی و تست‌شده‌اند. اتصال‌ها فعلاً فقط تعریف و فعال/غیرفعال
می‌شوند و هنوز Connector اجرایی، تست اتصال، همگام‌سازی و Retry ندارند. مقایسه
کامل فروشندگان، برنامه مربیگری و جست‌وجوی معنایی نیز برای تکمیل هدف ۱۲‌گانه
باقی مانده‌اند؛ تا آن زمان این نسخه نباید به‌عنوان نسخه نهایی عمومی معرفی شود.

## نکات امنیتی

- هیچ کلید API نباید داخل کد یا Git قرار گیرد.
- کلیدی که قبلاً داخل نسخه اولیه `test.py` بوده باید باطل و جایگزین شود.
- حساب محلی فقط برای توسعه و اجرای بدون Docker فعال است و در حالت production
  غیرفعال می‌شود؛ در استقرار اصلی ورود از Keycloak/OIDC انجام می‌شود.
- در تولید، HTTPS، MFA، رمزنگاری Secretها، پشتیبان‌گیری و سیاست نگهداری صوت را
  فعال کنید.
- ارسال خودکار پیام به‌طور پیش‌فرض روی «نیازمند تأیید مدیر» قرار دارد.
