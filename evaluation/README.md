# ارزیابی کیفیت رونویسی

این ابزار، متن مرجع و متن تولیدشده را بدون فراخوانی سرویس هوش مصنوعی مقایسه می‌کند و WER، CER، دقت موجودیت‌ها، دقت اعداد و در صورت وجود قطعه‌های زمان‌دار، دقت timestamp را در JSON و HTML گزارش می‌دهد.

نمونه همراه مخزن ساختگی و غیرحساس است؛ بنابراین فقط درست‌کارکردن ابزار را ثابت می‌کند و **هیچ ادعایی درباره دقت تماس واقعی یا رسیدن به ۸۵٪ ایجاد نمی‌کند**.

## اجرا

از ریشه مخزن:

```powershell
python evaluation/run_evaluation.py
python -m unittest discover -s evaluation/tests -v
```

خروجی‌ها در `evaluation/results/latest_report.json` و `latest_report.html` نوشته می‌شوند.

## افزودن دیتاست واقعی

1. برای هر تماس، رونویسی مرجع را یک بازبین فارسی‌زبان با شنیدن صوت تهیه کند.
2. رونویسی مدل را بدون ویرایش انسانی در `hypothesis_text` قرار دهید.
3. صوت را فقط در فضای کنترل‌شده نگه دارید. قرار دادن صوت واقعی، شماره تلفن یا نام مشتری در Git ممنوع است.
4. یک manifest مطابق `references/sample_dataset.json` بسازید و `contains_real_calls` را فقط وقتی `true` کنید که نمونه‌ها واقعاً تماس واقعی و دارای رضایت و ناشناس‌سازی مناسب باشند.
5. اجرا کنید:

```powershell
python evaluation/run_evaluation.py --dataset C:\secure-evaluation\dataset.json
```

`audio_path` اختیاری و نسبت به محل manifest است. ابزار وجود فایل را ثبت می‌کند ولی آن را پخش یا به سرویس خارجی ارسال نمی‌کند. برای واژه‌های تخصصی و code-switching، نوع موجودیت مناسب در `reference_entities` و خروجی متناظر مدل در `predicted_entities` ثبت شود.

## تعریف معیارها

- WER/CER بر مبنای فاصله Levenshtein و متن نرمال‌شده محاسبه می‌شوند.
- «دقت» موجودیت و عدد، recall چندمجموعه‌ای پس از نرمال‌سازی دقیق است؛ precision و F1 نیز در JSON وجود دارند.
- اعداد فارسی و عربی به رقم لاتین نرمال می‌شوند، اما «دوازده» و `۱۲` معادل تلقی نمی‌شوند؛ این تفاوت عمداً خطای رونویسی عدد را آشکار می‌کند.
- timestampها بر اساس ترتیب قطعه و تلرانس پیش‌فرض ۰٫۷۵ ثانیه سنجیده می‌شوند.
